# Muhammad Ali Butt — ML/AI Portfolio

A modern, responsive personal portfolio website showcasing my work, machine learning projects, technical skills, and AI development journey.

## 🚀 Overview

This portfolio is designed to present my projects and skills as an aspiring **Machine Learning / AI Engineer**. It features a clean, minimal interface with sections for my introduction, technical stack, selected projects, and contact information.

## 📂 Featured Projects

### Disease Prediction from Medical Data

A machine learning project that predicts the likelihood of heart disease using patient health metrics such as age, cholesterol, and blood pressure.

### Handwritten Character Recognition

A CNN-based project using EMNIST to recognize handwritten characters, with custom segmentation for real-time sentence recognition.

### Credit Scoring Model

An end-to-end machine learning pipeline that predicts loan default risk and compares multiple classifiers using cross-validated ROC-AUC.
